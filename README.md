# UAV Post-Flight Performance Analysis Platform

A small Python engineering portfolio project for inspecting hypothetical fixed-wing UAV flight data, calculating electrical performance metrics, comparing illustrative scenarios, and plotting results. The supplied datasets are **hypothetical synthetic teaching data**, not recorded aircraft flights. This project is not a validated aircraft performance model and must not be used to predict or certify real aircraft performance.

## Setup and Commands

From the project root in PowerShell, create or activate the environment and install dependencies:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Run the automated unit tests:

```powershell
python -m unittest discover -s tests -v
```

Run the principal analyses:

```powershell
python src\uav_flight_analysis.py
python src\uav_flight_comparison.py
python "src\flight comparison.py"
```

These scripts open Matplotlib windows when a graphical backend is available. For a headless run, set `$env:MPLBACKEND = "Agg"` in PowerShell before running them; calculations still run, but plots are not displayed interactively.

The input-driven exercises remain available as `python src\lesson3.py` and `python src\lesson4.py`.

`python src\create_flight_B.py` regenerates `data/hypothetical_fixed_wing_flight_B.csv` from Flight A using a 15% current increase. It writes to the existing Flight B filename; keep a copy first if you need to retain the supplied dataset version.

## Data and Engineering Methods

Both CSV files are hypothetical synthetic teaching datasets. The baseline file contains 1,201 samples at one-second intervals over 20 minutes, with 11 columns including time, flight phase, airspeed, altitude, battery voltage/current, electrical power, cumulative energy, and estimated battery remaining. The Flight B file represents an illustrative sensitivity case generated by increasing battery current by 15%; voltage, airspeed, and duration are kept unchanged by that generator.

The scripts use the following calculations:

- Electrical power: $P = V I$.
- Energy over a time interval: trapezoidal integration of adjacent power samples, $\Delta E = \frac{P_i + P_{i+1}}{2} \frac{\Delta t}{3600}$ Wh when time is in seconds.
- Total energy: sum of interval energy. Average power in the main analysis is total integrated energy divided by elapsed time; the comparison scripts also report a sample-wise arithmetic mean of power.
- Energy by flight phase: each time interval is assigned to the phase on its preceding sample.
- Battery remaining in the Flight B generator: linear nominal-energy bookkeeping using 222 Wh, clipped to 0-100%. This is an estimate encoded in the synthetic-data exercise, not a battery state-of-charge model.

The main analysis checks required columns, missing cells, timestamp ordering, nonnegative voltage/current/airspeed, and differences between supplied and recalculated power/energy. The unit tests cover the simple power, trapezoidal energy, and average-power helpers.

## Current Results

Results below were produced by running the scripts against the supplied synthetic datasets. They describe only those data and simplified calculations.

| Program and case | Duration | Average power | Maximum power | Total energy |
|---|---:|---:|---:|---:|
| `uav_flight_analysis.py`, Flight A | 20.00 min | 230.61 W (energy/time) | 509.18 W | 76.87 Wh |
| `uav_flight_comparison.py`, baseline | 20.00 min | 230.66 W (sample mean) | 509.17 W | 76.87 Wh |
| `uav_flight_comparison.py`, illustrative 10% higher-power case | 20.00 min | 253.73 W (sample mean) | 560.09 W | 84.56 Wh |
| `flight comparison.py`, Flight A CSV | 20.00 min | 230.66 W (sample mean) | 509.18 W | 76.87 Wh |
| `flight comparison.py`, Flight B CSV | 20.00 min | 265.26 W (sample mean) | 585.56 W | 88.40 Wh |

The baseline analysis found no missing cells or unexpected timestamp intervals. Recalculated power differed from the supplied power column by at most 0.0218 W, and integrated total energy differed from the supplied final cumulative-energy value by 0.0005 Wh. Flight-phase energy from that run was 8.14 Wh (takeoff/climb), 17.46 Wh (climb), 39.96 Wh (cruise), 7.50 Wh (descent), and 3.82 Wh (landing), subject to output rounding.

The 10% power comparison is a separate mathematical sensitivity exercise that scales the baseline power samples directly. It is not the same dataset as the 15%-current Flight B CSV.

## Assumptions and Limitations

- All flight values are hypothetical synthetic teaching data. They should not be represented as empirical flight-test evidence.
- The scenario comparisons hold duration and/or other recorded quantities fixed while scaling current or power. They do not model changes in aircraft dynamics, flight duration, airspeed, altitude, propulsion efficiency, or control response.
- Power is computed as terminal voltage times current; effects such as sensor error, transient electrical behavior, wiring losses, and motor/propeller efficiency are not modeled.
- Trapezoidal integration assumes power varies linearly between samples. The average-power comparison values use a simple mean of samples and can differ slightly from integrated energy divided by elapsed duration.
- The estimated battery percentage uses a fixed nominal 222 Wh capacity and linear energy accounting; it does not model voltage-dependent capacity, discharge limits, temperature, aging, or battery chemistry behavior.
- The current tests cover calculation helpers, not flight-data validation, plot rendering, or physical model validity.

## Dependencies

The calculations, CSV access, and tests use the Python standard library. Matplotlib is the only declared external dependency and is used for plots.
